# Project Governance

`whitecollarboxingtraining.github.io` is maintained by [Sebastien Rousseau](https://sebastienrousseau.com/).

All changes flow through a single active release iteration pull request (`feat/v<next-version>`) targeting the default branch (`master`) and must pass all automated CI and WCAG 2.2 Level AAA quality gates prior to merge.
