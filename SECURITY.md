# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.0.2` | :white_check_mark: |
| `< 0.0.2` | :x: |

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/sebastienrousseau/whitecollarboxingtraining.github.io/security/advisories/new). Do not open public issues for undisclosed security vulnerabilities.
